# ADR-005 — Governance levels + evidence_strength ortogonal

**Status:** accepted (baseline)

Levels 0–3 (governance dimension). `evidence_strength` ortogonal.
Baseline disponibiliza `hmac_internal` e `dev_signed`.
`external_anchor`, `customer_signed`, `icp_brasil_tsa` são `planned`.

GovAI **não vende, descreve ou marca** capability como "regulatory-grade externo"
no baseline.
